# Number Guessing Game

A simple browser-based number guessing game built with HTML, CSS, and JavaScript.

## How it works

- The game randomly generates a secret number between 1 and 100.
- The player enters a guess in the input field.
- Clicking the **Check** button compares the guess to the secret number.
- The game shows whether the guess is too high, too low, or correct.

## Files

- `index.html` - Main game page and layout.
- `style.css` - Page styling and responsive design.
- `game.js` - Game logic for validating guesses and showing feedback.

## Usage

1. Open `index.html` in a web browser.
2. Enter a number between 1 and 100.
3. Click **Check** to submit your guess.
4. Follow the feedback until you find the correct number.

## Notes

- The page uses Bootstrap for button styling and layout helpers.
- The input field accepts only numeric guesses between 1 and 100.
- Refresh the page to start a new game with a new secret number.
